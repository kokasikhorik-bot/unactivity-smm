# 🚀 Быстрый старт - Unactivity SMM

## Шаг 1: Установка

Запустите файл `SETUP.bat` (двойной клик)

Или вручную:
```bash
npm install
cd gui-app
npm install
cd ..
```

## Шаг 2: Запуск веб-сервера

Запустите файл `START_SERVER.bat` (двойной клик)

Или вручную:
```bash
npm start
```

Сервер будет доступен на: **http://localhost:3000**

## Шаг 3: Запуск GUI приложения

Запустите файл `START_GUI.bat` (двойной клик)

Или вручную:
```bash
cd gui-app
npm start
```

## Шаг 4: Настройка GUI

1. В GUI приложении нажмите "⚙️ Настройки"
2. Заполните:
   - **Путь к проекту**: полный путь к этой папке (например: `C:\Users\User\Videos\Unactivity SMM`)
   - **OPTSMM API Key**: `zhLKUyf12DwMSsuStEfI9eo99AwvdBEL7pDZ9Fv8CnoUzxGUP7CiuhwdWPSR`
   - **GitHub Repository URL**: URL вашего репозитория (создайте на GitHub)
3. Нажмите "Сохранить"

## Шаг 5: Создание первого пинкода

### Через GUI (рекомендуется):
1. Выберите услугу
2. Укажите количество
3. Нажмите "Сгенерировать пинкод"
4. Скопируйте пинкод
5. Нажмите "Залить на GitHub" (опционально)

### Через веб-админку:
1. Откройте http://localhost:3000/admin.html
2. Выберите услугу
3. Укажите количество
4. Нажмите "Сгенерировать пинкод"

## Шаг 6: Тестирование

1. Откройте http://localhost:3000
2. Введите созданный пинкод
3. Выберите услугу
4. Заполните данные
5. Запустите накрутку

## 🌐 Доступ к сайту

- **Главная страница**: http://localhost:3000
- **Админ панель**: http://localhost:3000/admin.html
- **Статус заказов**: http://localhost:3000 → вкладка "Статус"

## 🎯 Основные функции

### Для клиентов:
1. Ввод пинкода
2. Выбор услуги (если несколько)
3. Ввод ссылки и количества
4. Запуск накрутки
5. Отслеживание статуса

### Для администратора:
1. Создание пинкодов с несколькими услугами
2. Просмотр всех пинкодов
3. Просмотр всех заказов
4. Автоматическая синхронизация с GitHub

## 🚀 Деплой на Railway

1. Создайте репозиторий на GitHub
2. Загрузите проект:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin YOUR_REPO_URL
git push -u origin main
```

3. Зайдите на https://railway.app
4. Создайте проект из GitHub репозитория
5. Добавьте переменные окружения:
   - `OPTSMM_API_KEY`: ваш ключ
   - `PORT`: 3000

Подробнее в файле `DEPLOY.md`

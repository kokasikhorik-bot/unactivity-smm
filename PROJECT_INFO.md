# 📋 Unactivity SMM - Полная информация о проекте

## 🎯 Описание проекта

**Unactivity SMM** - это профессиональная платформа для продажи услуг SMM накрутки через систему пинкодов с интеграцией OPTSMM API.

### Основные компоненты:

1. **Веб-сайт** - красивый интерфейс для клиентов
2. **Админ панель** - веб-интерфейс для управления
3. **Desktop GUI** - приложение для создания пинкодов и управления
4. **API сервер** - Express.js бэкенд с интеграцией OPTSMM

## 🌟 Ключевые возможности

### Для клиентов:
- ✅ Простой ввод пинкода
- ✅ Выбор из нескольких услуг (если доступно)
- ✅ Ввод ссылки и количества
- ✅ Мгновенный запуск накрутки
- ✅ Отслеживание статуса в реальном времени
- ✅ Адаптивный дизайн для всех устройств

### Для администратора:
- ✅ Генерация уникальных 16-значных пинкодов
- ✅ Привязка нескольких услуг к одному пинкоду
- ✅ Просмотр всех пинкодов и их статусов
- ✅ Мониторинг всех заказов
- ✅ Desktop приложение для удобного управления
- ✅ Автоматическая синхронизация с GitHub
- ✅ Веб-админка для быстрого доступа

## 🔌 API Endpoints

### Публичные (для клиентов):

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/verify-pincode` | Проверка пинкода |
| POST | `/api/create-order` | Создание заказа |
| GET | `/api/order-status/:orderId` | Статус заказа |
| GET | `/api/orders-by-pincode/:pincode` | Все заказы по пинкоду |

### Административные:

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/services` | Список услуг OPTSMM |
| POST | `/api/admin/create-pincode` | Создание пинкода |
| GET | `/api/admin/pincodes` | Все пинкоды |
| GET | `/api/admin/orders` | Все заказы |

## 🔐 Безопасность

### Реализованные меры:

1. **API ключи в переменных окружения**
   - Не хранятся в коде
   - Загружаются из `.env` файла
   - `.env` в `.gitignore`

2. **Валидация данных**
   - Проверка пинкодов
   - Валидация количества
   - Проверка использованных услуг

3. **Уникальность пинкодов**
   - Генерация с проверкой на дубликаты
   - 16 символов (36^16 комбинаций)

4. **Одноразовое использование**
   - Каждая услуга используется один раз
   - Автоматическая блокировка после использования

### Рекомендации:

- ⚠️ Используйте HTTPS в продакшене
- ⚠️ Регулярно меняйте API ключи
- ⚠️ Делайте бэкапы database.json
- ⚠️ Ограничьте доступ к админ панели
- ⚠️ Используйте приватный GitHub репозиторий

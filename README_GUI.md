## 📋 Использование

### Создание пинкода:

1. Перейдите на вкладку **"Создать пинкод"**
2. Выберите услугу из списка
3. Укажите количество
4. (Опционально) Добавьте описание
5. Нажмите **"+ Добавить ещё услугу"** для добавления нескольких услуг
6. Нажмите **"🎫 Сгенерировать пинкод"**
7. Скопируйте пинкод кнопкой **"📋 Копировать"**
8. Нажмите **"🚀 Залить на GitHub"** для автоматического коммита

### Просмотр пинкодов:

1. Перейдите на вкладку **"Пинкоды"**
2. Нажмите **"🔄 Обновить"**
3. Увидите таблицу со всеми пинкодами, услугами и статусами

### Просмотр заказов:

1. Перейдите на вкладку **"Заказы"**
2. Нажмите **"🔄 Обновить"**
3. Увидите таблицу со всеми заказами клиентов

## 🐛 Troubleshooting

### Ошибка "Путь к проекту не найден"
- Убедитесь, что указали правильный путь
- Путь должен быть абсолютным
- В папке должен быть файл `database.json`

### Ошибка "Не удалось загрузить услуги"
- Проверьте OPTSMM API ключ
- Убедитесь в наличии интернета

### Ошибка при пуше в GitHub
- Проверьте настройку Git: `git config --global user.name` и `user.email`
- Убедитесь в правах на запись в репозиторий
- Проверьте, что репозиторий инициализирован

### Приложение не запускается
- Убедитесь, что у вас Windows 10/11
- Попробуйте запустить от имени администратора
- Проверьте антивирус (может блокировать)

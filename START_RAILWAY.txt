Проблема: Railway не деплоится
Решение:
  1. Проверьте логи в Railway → Deployments
  2. Убедитесь, что OPTSMM_API_KEY добавлен
  3. Проверьте package.json - должен быть "start": "node server.js"

Проблема: Сайт не открывается
Решение:
  1. Проверьте, что домен сгенерирован (Settings → Networking)
  2. Проверьте логи - сервер должен быть запущен
  3. Подождите 1-2 минуты после деплоя

Проблема: Пинкоды не удаляются
Решение:
  1. Проверьте GitHub - есть ли новые коммиты после использования?
  2. Проверьте логи сервера - должно быть "Пинкод удален"
  3. Проверьте, что Git настроен в .exe приложении

# 📝 История изменений Unactivity SMM Manager

## Версия 1.0.0 (2026-05-04) - ТЕКУЩАЯ

### 🐛 Исправления
- **Удалено дублирование поля API ключа** в модальном окне настроек
  - Было: 2 поля для API ключа (одно редактируемое, другое readonly)
  - Стало: 1 редактируемое поле для API ключа
  - Файл: `gui-app/index.html`

### ✨ Новые функции
- **Автоматическая загрузка услуг при старте приложения**
  - Услуги загружаются сразу после загрузки конфигурации
  - Не требуется ручное нажатие кнопки "Загрузить услуги"
  - Файл: `gui-app/renderer.js`

- **Улучшенные индикаторы загрузки**
  - Дропдауны показывают "🔄 Загрузка услуг..." во время загрузки
  - Показывают "❌ API ключ не настроен" если ключ отсутствует
  - Показывают "❌ Ошибка загрузки" если произошла ошибка
  - Файл: `gui-app/renderer.js`

### 🔧 Улучшения
- **Расширенное логирование**
  - Добавлены детальные логи в консоль DevTools
  - Логи показывают каждый шаг загрузки услуг
  - Логи показывают ошибки с подробностями
  - Файлы: `gui-app/main.js`, `gui-app/renderer.js`

- **Улучшенная обработка ошибок**
  - Статус загрузки показывается в настройках
  - Цветовая индикация (синий=загрузка, зеленый=успех, красный=ошибка)
  - Автоматическое скрытие успешного статуса через 5 секунд

### 📦 Технические детали
- **API Endpoint**: `https://optsmm.ru/api/v2?action=services&key=...`
- **Метод**: Прямой вызов из Electron main process (не через локальный сервер)
- **Timeout**: 20 секунд
- **User-Agent**: Mozilla/5.0

### 📄 Документация
- Добавлен `TESTING_GUIDE.md` - подробное руководство по тестированию
- Добавлен `QUICK_START.txt` - быстрый старт для пользователя
- Добавлен `CHANGELOG.md` - история изменений

# Unactivity SMM Manager - Desktop GUI

Десктоп приложение для управления пинкодами и заказами Unactivity SMM.

## 🚀 Быстрый старт

### Установка

```bash
npm install
```

### Запуск

```bash
npm start
```

### Сборка exe файла

```bash
npm run build
```

Готовый exe файл будет в папке `dist/`

## 📖 Использование

### 1. Первоначальная настройка

При первом запуске:
1. Нажмите кнопку "⚙️ Настройки"
2. Заполните поля:
   - **Путь к проекту**: полный путь к папке с server.js (например: `C:\projects\unactivity-smm`)
   - **OPTSMM API Key**: ваш API ключ от OPTSMM
   - **GitHub Repository URL**: URL вашего GitHub репозитория (например: `https://github.com/username/unactivity-smm.git`)
3. Нажмите "Сохранить"

### 2. Создание пинкода

1. Перейдите на вкладку "Создать пинкод"
2. Выберите услугу из выпадающего списка
3. Укажите количество
4. Добавьте описание (опционально)
5. Нажмите "+ Добавить ещё услугу" для добавления нескольких услуг к одному пинкоду
6. Нажмите "🎫 Сгенерировать пинкод"
7. Скопируйте пинкод кнопкой "📋 Копировать"
8. Нажмите "🚀 Залить на GitHub" для автоматического коммита и пуша

### 3. Просмотр пинкодов

1. Перейдите на вкладку "Пинкоды"
2. Нажмите "🔄 Обновить"
3. Увидите таблицу со всеми пинкодами, их услугами и статусами

### 4. Просмотр заказов

1. Перейдите на вкладку "Заказы"
2. Нажмите "🔄 Обновить"
3. Увидите таблицу со всеми заказами клиентов

## 🔧 Технические детали

### Как работает

1. **Создание пинкода**: 
   - Приложение генерирует уникальный 16-значный код
   - Сохраняет данные в `database.json` в папке проекта
   - Опционально коммитит и пушит изменения в GitHub

2. **Просмотр данных**:
   - Читает `database.json` из указанной папки проекта
   - Отображает актуальную информацию

3. **Git интеграция**:
   - Использует `simple-git` для работы с Git
   - Автоматически делает `git add`, `git commit`, `git push`

### Структура конфигурации

Настройки хранятся в:
- **Windows**: `%APPDATA%\unactivity-smm-manager\config.json`
- **macOS**: `~/Library/Application Support/unactivity-smm-manager/config.json`
- **Linux**: `~/.config/unactivity-smm-manager/config.json`

### Требования

- Node.js 16+
- Git установлен и настроен
- Доступ к GitHub репозиторию

## 🐛 Troubleshooting

### Ошибка "Путь к проекту не найден"
- Убедитесь, что указали правильный путь к папке с `server.js`
- Путь должен быть абсолютным (например: `C:\projects\unactivity-smm`)

### Ошибка "Не удалось загрузить услуги"
- Проверьте правильность OPTSMM API ключа
- Убедитесь, что есть интернет соединение

### Ошибка при пуше в GitHub
- Убедитесь, что Git настроен (`git config --global user.name` и `user.email`)
- Проверьте, что у вас есть права на запись в репозиторий
- Убедитесь, что репозиторий инициализирован и есть remote origin

### Приложение не запускается
- Убедитесь, что установлены все зависимости (`npm install`)
- Проверьте версию Node.js (`node --version` должна быть 16+)

## 📝 Примечания

- Приложение работает локально и не требует интернета для просмотра данных
- Для создания пинкодов нужен интернет (загрузка услуг из OPTSMM)
- Для пуша в GitHub нужен интернет и настроенный Git
- База данных хранится в файле `database.json` в папке проекта

## 🎯 Быстрый старт

1. **Запустите приложение**
   ```
   gui-app\dist\Unactivity SMM Manager 1.0.0.exe
   ```

2. **Проверьте консоль DevTools**
   - Должно появиться: "✅ Конфигурация загружена"

   - Откройте `DIAGNOSTIC_CHECKLIST.txt`
   - Следуйте инструкциям
   - Отправьте логи из консоли

## 🔄 Workflow

1. Запуск приложения → Автозагрузка услуг
2. Создание пинкода → Сохранение в database.json
3. Автоматический git push → Обновление GitHub
4. Клиент вводит пинкод → Создание заказа
5. Заказ отправляется в OPTSMM → Выполнение
6. Пинкод удаляется после использования

## 🐛 Решение проблем

### Услуги не загружаются
1. Откройте DevTools (открывается автоматически)
2. Проверьте консоль на ошибки
3. Откройте настройки (⚙️)
4. Нажмите "🔄 Загрузить услуги из OPTSMM"
5. Проверьте статус (зеленый/красный блок)

### API ключ не настроен
1. Настройки (⚙️)
2. Вставьте API ключ (см. выше)
3. Сохранить
4. Перезапустите приложение

### GitHub автопуш не работает
1. Настройки (⚙️)
2. Вставьте GitHub Token (см. выше)
3. Сохранить
4. Попробуйте создать пинкод снова

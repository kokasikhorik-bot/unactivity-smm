# Unactivity SMM - Сервис накрутки с пинкодами

Профессиональный веб-сервис для продажи услуг SMM накрутки через OPTSMM API с системой пинкодов и десктоп приложением для управления.

## 🚀 Возможности

- ✨ Современный интерфейс без отвлекающих элементов
- 🎫 Система уникальных 16-значных пинкодов
- 📦 Несколько услуг на один пинкод
- 📊 Отслеживание статуса заказов в реальном времени
- 🖥️ Десктоп GUI приложение для управления
- 🔐 Админ панель
- 🌟 Интеграция с OPTSMM API
- 🚀 Готово к деплою на Railway
- 📱 Адаптивный дизайн

## 📦 Установка веб-сервера

1. Установите зависимости:
```bash
npm install
```

2. Настройте `.env` файл (уже создан с API ключом)

3. Запустите сервер:
```bash
npm start
```

4. Откройте браузер: `http://localhost:3000`

## 🖥️ Установка GUI приложения

1. Перейдите в папку gui-app:
```bash
cd gui-app
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm start
```

4. Для сборки exe файла:
```bash
npm run build
```

## 🎯 Использование GUI приложения

### Первоначальная настройка:
1. Откройте настройки (⚙️)
2. Укажите путь к проекту (где находится server.js)
3. Введите OPTSMM API ключ
4. Укажите URL GitHub репозитория
5. Сохраните настройки

### Создание пинкода:
1. Выберите услугу из списка
2. Укажите количество
3. Добавьте описание (опционально)
4. Нажмите "+ Добавить услугу" для добавления нескольких услуг
5. Нажмите "Сгенерировать пинкод"
6. Скопируйте пинкод
7. Нажмите "Залить на GitHub" для автоматического коммита

### Просмотр данных:
- Вкладка "Пинкоды" - все созданные пинкоды с их услугами
- Вкладка "Заказы" - все заказы клиентов

## 📖 Использование веб-сайта

### Для клиентов:
1. Откройте главную страницу
2. Введите полученный пинкод
3. Выберите услугу из доступных
4. Заполните данные (ссылка, количество)
5. Запустите накрутку
6. Отслеживайте статус в разделе "Статус"

### Для администратора:
1. Откройте `/admin.html`
2. Выберите услуги из списка OPTSMM
3. Укажите количество для каждой
4. Сгенерируйте пинкод
5. Отправьте пинкод клиенту

## 🚀 Деплой на Railway

1. Создайте репозиторий на GitHub
2. Залейте проект:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin YOUR_GITHUB_REPO_URL
git push -u origin main
```

3. Зайдите на [Railway.app](https://railway.app)
4. Создайте новый проект из GitHub репозитория
5. Добавьте переменные окружения:
   - `OPTSMM_API_KEY` - ваш API ключ
   - `PORT` - 3000
6. Railway автоматически задеплоит проект

## 🔧 API Endpoints

- `GET /api/services` - Список услуг OPTSMM
- `POST /api/admin/create-pincode` - Создание пинкода с несколькими услугами
- `GET /api/admin/pincodes` - Все пинкоды
- `POST /api/verify-pincode` - Проверка пинкода
- `POST /api/create-order` - Создание заказа
- `GET /api/order-status/:orderId` - Статус заказа
- `GET /api/orders-by-pincode/:pincode` - Заказы по пинкоду
- `GET /api/admin/orders` - Все заказы

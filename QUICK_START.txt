   gui-app\dist\Unactivity SMM Manager 1.0.0.exe

2. Приложение откроется с консолью разработчика (DevTools)

3. Проверьте консоль - должны появиться сообщения:
   ✅ Конфигурация загружена
   🔄 Автоматическая загрузка услуг при старте...

5. Если НЕ загрузились:
   - Откройте настройки (⚙️)
   - Проверьте API ключ
   - Нажмите "🔄 Загрузить услуги из OPTSMM"
   - Смотрите статус (зеленый/красный блок)

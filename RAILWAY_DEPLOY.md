## 🚀 Способ 1: Через веб-интерфейс Railway (Самый простой)

### Шаг 1: Подготовка GitHub репозитория

Код уже залит на GitHub: `https://github.com/kokasikhorik-bot/unactivity-smm`

Убедитесь, что в репозитории есть:
- ✅ `server.js`
- ✅ `package.json`
- ✅ `database.json`
- ✅ `public/` (клиентский сайт)
- ✅ `.env` (НЕ должен быть в репозитории!)

### Шаг 2: Создание проекта на Railway

1. **Откройте Railway**
   - Перейдите на [railway.app](https://railway.app)
   - Нажмите "Login" → "Login with GitHub"
   - Авторизуйтесь через GitHub

2. **Создайте новый проект**
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Найдите и выберите `kokasikhorik-bot/unactivity-smm`
   - Нажмите "Deploy Now"

3. **Дождитесь первого деплоя**
   - Railway автоматически:
     - Установит зависимости (`npm install`)
     - Запустит сервер (`npm start`)
   - Это займёт 1-2 минуты

### Шаг 3: Настройка переменных окружения

1. **Откройте настройки**
   - Кликните на ваш проект
   - Перейдите в "Variables"

2. **Добавьте переменные**
   - Нажмите "New Variable"
   - Добавьте:
     ```
     OPTSMM_API_KEY = zhLKUyf12DwMSsuStEfI9eo99AwvdBEL7pDZ9Fv8CnoUzxGUP7CiuhwdWPSR
     ```
   - Нажмите "Add"

3. **Перезапустите деплой**
   - Railway автоматически перезапустит приложение
   - Или нажмите "Redeploy" вручную

### Шаг 4: Получение публичного URL

1. **Откройте Settings**
   - Перейдите в "Settings" → "Networking"

2. **Сгенерируйте домен**
   - Нажмите "Generate Domain"
   - Railway создаст URL вида: `https://unactivity-smm-production.up.railway.app`

3. **Скопируйте URL**
   - Это ваш публичный адрес сайта!
   - Клиенты будут использовать этот URL

### Шаг 5: Проверка работы

1. **Откройте ваш URL в браузере**
   - Должна открыться главная страница с формой ввода пинкода

2. **Проверьте логи**
   - В Railway перейдите в "Deployments"
   - Кликните на последний деплой
   - Проверьте логи - должно быть:
     ```
     🚀 Сервер запущен на http://localhost:3000
     ```

3. **Протестируйте пинкод**
   - Создайте пинкод через десктоп приложение
   - Введите его на сайте
   - Проверьте, что заказ создаётся

## 🔄 Автоматическое обновление

Railway автоматически обновляет приложение при каждом push на GitHub:

1. **Создайте пинкод** в десктоп приложении
2. **Приложение автоматически**:
   - Сохраняет в `database.json`
   - Делает `git commit`
   - Делает `git push` на GitHub
3. **Railway автоматически**:
   - Обнаруживает изменения
   - Запускает новый деплой
   - Обновляет приложение (30-60 секунд)

### Проверка автообновления

1. Создайте пинкод через .exe
2. Откройте Railway → Deployments
3. Через 10-20 секунд появится новый деплой
4. Дождитесь завершения (зелёная галочка)
5. Пинкод будет доступен на сайте

## 🐛 Решение проблем

### Проблема: "Application failed to respond"

**Причина**: Сервер не запустился или упал

**Решение**:
1. Проверьте логи в Railway
2. Убедитесь, что `OPTSMM_API_KEY` настроен
3. Проверьте, что `PORT` не задан (Railway сам его установит)

### Проблема: "Build failed"

**Причина**: Ошибка при установке зависимостей

**Решение**:
1. Проверьте `package.json`
2. Убедитесь, что все зависимости в `dependencies`
3. Попробуйте локально: `npm install`

### Проблема: Пинкоды не обновляются

**Причина**: Git push не работает или Railway не обновляется

**Решение**:
1. Проверьте GitHub - есть ли новые коммиты?
2. Проверьте Railway → Deployments - есть ли новые деплои?
3. Вручную запустите Redeploy в Railway

### Проблема: 404 Not Found

**Причина**: Неправильный URL или сервер не запущен

**Решение**:
1. Проверьте URL - должен быть `https://your-app.up.railway.app`
2. Проверьте логи - сервер должен быть запущен
3. Проверьте, что `public/` папка есть в репозитории
